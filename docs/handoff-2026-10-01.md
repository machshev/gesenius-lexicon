# Handoff, 2026-10-01: frontier pipeline after the segmentation check

## How to run this session

You are the **orchestrator**. Do not read files, run commands or edit code
yourself. Every piece of work goes to a subagent through the Agent tool, with
a self-contained prompt: the subagent sees none of this conversation, so give
it the paths, commands and acceptance criteria it needs from this file.
Your own job is to:

- pick the next task, choose the model, write the brief;
- read the report, decide, and relay the outcome to the user;
- ask the user before anything that costs real money or time (see the
  cost gates below).

Run independent tasks in parallel, in one message with several Agent calls.
Make each subagent commit its own work; `AGENTS.md` asks for commits as we
go. The attribution line is `Co-Authored-By: <model> <noreply@anthropic.com>`.

### Choosing the subagent model

| Model | Use for | Examples here |
|---|---|---|
| `haiku` | Mechanical work with an unambiguous recipe and checkable output | running the converter and import, collecting counts, rendering page previews, `cargo test`, finding pages by running-head letter |
| `sonnet` | Ordinary engineering: code changes in Python or Rust, writing tests, debugging with clear evidence, diff analysis | fixing segmentation logic, adding a converter test, wiring an export |
| `opus` | Judgement: reading the scans against the output (pointed Hebrew, Arabic, Syriac), deciding whether a segmentation is right, design questions about the data model, reviewing a change before it is committed | verifying entry boundaries on a page image, deciding how letter introductions are represented |

Default to the cheapest model that can do the task reliably. Move up a tier
when a report comes back wrong or vague, rather than starting high. Visual
checks of the printed page always go to `opus`: the cheaper models misread
vowel points and miss small headwords. The transcription itself is done by
`claude-fable-5-1` *inside* the tools (`--model` default), so no subagent needs
to be Fable.

### Reproducing the check

```bash
S=<scratchpad>
args=(); for f in corpus/frontier/robinson-1854/pass2/*.json; do args+=(--transcription "$f"); done
python3 tool/frontier-to-alto.py "${args[@]}" --output $S/alto
rm -rf $S/corpus && cp -r corpus/machine $S/corpus
target/debug/gesenius --corpus $S/corpus import-frontier --edition robinson-1854 $S/alto/*.json
target/debug/gesenius --corpus $S/corpus validate
```

The import prints a `run_path`. The per-page `parsed.json` there has
`entries` and `assignments` (`[region, line, {kind}]`; `unparsed` marks lines
outside any entry). The rasters are in
`.cache/gesenius/frontier/robinson-1854/raster/pdf-NNNN.png` (400 DPI, about
2050x3490). Only the 24 pilot pages are rasterised so far. To view a page,
crop each column and scale it to about 1400 px tall; full pages are too
small to read.
